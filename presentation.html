Overview

Objectives & Agenda

  • Zero Boilerplate Runs: Caches auth state contextually to skip login steps.
  • Decoupled Network Layer: Isolates HTTP APIs from visual browsers.
  • Environment Control: Prevents invalid configuration deployments.
  • Dual-Track Pipelines: Fast smoke tests on PRs, nightly cross-browser sweeps.
🔍 Context-Ready

Core Engine

Decoupled Layer Architecture

⚙️ Configuration

`EnvManager` loads `.env.*` schemas and checks keys, casting strings to numbers and booleans prior to launching the suite.

🎭 POM Pages

`BasePage` wraps element interaction routines while specific pages declare selector locators (`LoginPage`, `DashboardPage`).

🧬 API Client

`ApiClient` handles network requests, custom errors, and context parsing independently of browser execution.

Authentication

Session State Orchestration

  • Run-Once Authentication: `auth.setup.ts` project logs in UI and serializes context.
  • Stored state JSON: Saved safely to `playwright/.auth/user.json` (gitignored).
  • Pre-Authenticated Projects: Browser projects seed `storageState` directly.
  • Isolated Login Specs: Uncached projects remain untouched to validate error scenarios.
// playwright.config.ts
projects: [
  {
    name: 'setup',
    testMatch: /auth\.setup\.ts/,
  },
  {
    name: 'chromium',
    dependencies: ['setup'],
    use: {
      storageState: AUTH_STORAGE_PATH,
    },
  }

API Layer

REST Endpoint Integration

  • Modular Controllers: Subclassed endpoint routes (`UserApi`, `AuthApi`) declare REST logic.
  • Isolated API Projects: Custom project configurations set separate `apiBaseUrl` and request headers.
  • Mock Personas: JSON mappings store employee profiles (`admin`, `essUser`) to ease assertions.

Observability

Context-Safe Logging & Hooks

  • Singleton Logger: Multi-level output (`debug`, `info`, `warn`, `error`) to console and file.
  • Preserved Context: Hook methods call Logger instances directly to ensure correct `this` binding.
  • Lifecycle Fixtures: Automatically formats start/end timelines, worker indices, and run durations.
// src/hooks/testHooks.ts
export function withTestHooks(test) {
  return test.extend({
    _lifecycle: [async ({}, use, testInfo) => {
      Logger.info('Test started', { title: testInfo.title });
      await use();
      Logger.info('Test finished', { status: testInfo.status });
    }, { auto: true }]
  });
}

Pipelines

CI/CD Run Strategy

  • PR Smoke Checks: Runs fast `@smoke` suites on Chromium only. Automatically cancels stale builds.
  • Nightly Matrix: Triggers daily cross-browser runs on Chrome, Firefox, and WebKit.
  • Playwright Caching: CI scripts cache browser binaries to shave minutes off pipeline duration.
⚡ PR Optimization

Saves server core hours by skipping secondary browser installations on intermediate branches.
